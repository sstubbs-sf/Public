How it runs

The workflow puts the argument before the HTML — and stops for agreement at the outline

1
Establish the argument. Audience, the decision they need to make, the one-sentence takeaway, and where the numbers came from.
2
Outline as headlines, then stop. Headline sentences, not topic labels — and explicit agreement before any HTML exists.
3
Build from the shell. Copy assets/shell.html, paste components from the gallery. Never write new CSS — if you are adding a rule, the component already exists.
4
Verify twice. Run the gate for what a script can read, then open it in a browser for what it cannot.
5
Hand over honestly. Report the path, the slide count, and every figure you could not source.
Why step 2 is a hard stop: restructuring an outline costs a minute. Restructuring twelve slides of finished HTML costs an hour — and by then the reader has stopped reading.

Iconography

326 icons ship in two families, and mixing them inside one grid is the defect you cannot see

Line family · 50 icons
  • 24-grid, stroke:currentColor, 1.6px, fill:none.
  • Light optical weight. Wrapper is .icon.
  • Neutral by design — no vendor or product marks.
Solid family · 276 icons
  • 64-grid, fill:currentColor declared inside the file.
  • Noticeably heavier. Wrapper is .icon solid.
  • Includes verticals and architecture objects; some read as vendor artwork.
Size non-square icons by height
Five are not square. Sizing the widest by width rendered it 26×7.36px — the correct aspect ratio, and an illegible smudge. Height-driven gives 91.81×26.00px.
45 icons need a dark chip
Their interior detail is painted hard white rather than knocked through, so it vanishes on a pale surface. Those go on .icon-chip deep.

Verification

The gate catches what looking cannot — and is honest about what it cannot judge

Structure and portability

Sandbox-safe storage and print(), navigation wiring, landscape print CSS, and no external reference of any kind.

Brand and accuracy

Official lockup present and not redrawn, no foreign brand in a brand slot, contrast rule enforced, and no token used but never declared.

Icon hygiene

Class collisions between inlined icons, duplicate referenced ids, and both icon families appearing inside one grid.

What it cannot judge: layout, the printed PDF, and navigation inside a sandboxed iframe. The gate reads source text — it cannot measure a rendered box, so those stay author checks in a real browser. A gate that claimed otherwise would be worse than none.

Getting started

Copy the shell, run the gate, hand over one file

  • assets/shell.html is the starting point for every deck; the one-pager shell is its portrait sibling.
  • references/components.md has copy-paste markup for every component, and a slide budget telling you when a slide is overloaded.
  • references/icon-index.md starts with Pick by concept, so you map a topic to an icon instead of scanning filenames.
To use it: ask for a deck and name the audience, the decision and the length. You will get an outline to approve before any HTML is written, then a single gate-checked .html file you can email as-is.
